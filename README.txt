GLAM BEAUTY PRODUCTS - COMPLETE WEBSITE PROJECT

FILES:
- index.html       Main home page with 12 products
- style.css        Main website design
- login.html       Login page
- register.html    Registration page
- auth.css         Login and registration page design
- script.js        Cart, registration demo and login demo
- images/          12 individual product illustration images

HOW TO OPEN:
1. Download and extract this ZIP.
2. Open the extracted Glam-Beauty-Complete folder in VS Code.
3. Keep all HTML, CSS and JS files in the main folder.
4. Keep the 12 SVG image files inside the images folder.
5. Open index.html in a browser or use Live Server.

IMPORTANT:
The 12 included images are simple original SVG product illustrations, not real product photographs.
You can replace them with your own product photos and keep the same filenames.
The login/register is only a front-end classroom demo using browser localStorage.
It is not secure real-world authentication. A real website needs a secure backend and database.
Change the sample email and phone number in index.html to your own details.
